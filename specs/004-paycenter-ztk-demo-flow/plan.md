## Design

### Layout Change

Wrap the phone frame in a `<div class="demo-wrapper">` flex row. Add `<aside class="use-case-panel">` to the left of the phone frame inside the wrapper. The outer `body` flex alignment (`justify-content: flex-end; padding-right: 27%`) is preserved so the entire wrapper stays right-positioned.

```
body (flex, right-aligned)
└── div.demo-wrapper (flex row, gap)
    ├── aside.use-case-panel   ← NEW
    │   └── fieldset > legend + label×4 (radio buttons)
    └── div.phone-frame        ← existing, unchanged
        └── div.phone-screen
            ├── img#slide-current
            ├── img#slide-incoming
            ├── div#left-zone
            ├── div#click-zone
            ├── div#cta-hotspot
            └── div#accept-hotspot
```

### State Changes

The JS state machine gains one field (`useCase`) and a new `reset()` function:

```
state.useCase     — tracks selected radio value
state.flowState   — 'blank' | 'carousel' | 'terms' | 'choose-receive'
state.carouselIndex
state.isAnimating
```

On load: `flowState = 'blank'`, phone screen has `background: #000`, both image slides are hidden (`display: none` or `src` left empty and `visibility: hidden`).

### Wire-up Logic

| Event | Handler |
|---|---|
| Radio "Enroll P2P" change | `activateEnrollP2P()` — sets `flowState='carousel'`, loads image 001, enables nav + CTA zones |
| Radio non-P2P change | `resetToBlank()` — clears images, disables all zones, `flowState='blank'` |
| Click right nav zone | existing `advance()` |
| Click left nav zone | existing `retreat()` |
| Click CTA hotspot | existing `showTerms()` |
| Click Accept hotspot | existing `showChooseScreen()` |

### Bug Fix

`CHOOSE_IMAGE` constant in existing code references `'images/Choose How to Receive Money P2P.png'` — file does not exist. Correct path: `'images/Choose How to Receive Money 01 P2P.png'`.

### No New Files

All changes are made to the single existing `ZTK Demo Project/index.html`.
