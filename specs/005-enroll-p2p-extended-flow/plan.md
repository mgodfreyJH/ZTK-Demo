# Implementation Plan: Enroll P2P Extended Flow – Choose, Select Account & Spinner

**Branch**: `005-enroll-p2p-extended-flow` | **Date**: 2026-05-19 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/005-enroll-p2p-extended-flow/spec.md`

## Summary

Extend `ZTK Demo Project/index.html` beyond the Terms & Conditions acceptance to complete the full Enroll P2P journey: two instant-swap radio-button screens (Choose How to Receive Money 01→02, Select Account 01→02), two Continue CTA slide transitions, a fade + CSS spinner processing state lasting 1 second, and a terminal Congratulations screen. The radio panel always resets any state to blank.

**Stack**: HTML5 / CSS3 / ES2020 — single `index.html`, no dependencies, no build step.

## Design

### State Machine Rename

`showChooseScreen()` currently sets `flowState = 'choose-receive'`. This must be renamed to `'choose-receive-01'` so the extended states can be added cleanly without ambiguity.

### New `flowState` Values

| State | Screen | Active Zone(s) |
|---|---|---|
| `choose-receive-01` | Choose How to Receive Money 01 P2P | `#choose-radio-hotspot` |
| `choose-receive-02` | Choose How to Receive Money 02 P2P | `#choose-continue-hotspot` |
| `select-account-01` | Select Account 01 P2P | `#select-radio-hotspot` |
| `select-account-02` | Select Account 02 P2P | `#select-continue-hotspot` |
| `processing` | Fade + spinner overlay | none |
| `congratulations` | Congratulations P2P | none |

### New Hotspot Elements (HTML)

Four `<div>` elements added inside `.phone-screen` following the existing hotspot pattern:

```html
<div id="choose-radio-hotspot"></div>
<div id="choose-continue-hotspot"></div>
<div id="select-radio-hotspot"></div>
<div id="select-continue-hotspot"></div>
```

All default `pointer-events: none`. Activated per-state.

### New Hotspot CSS

```css
#choose-radio-hotspot, #choose-continue-hotspot,
#select-radio-hotspot, #select-continue-hotspot {
  position: absolute;
  left: 0;
  width: 100%;
  pointer-events: none;
  cursor: pointer;
  z-index: 11;
  touch-action: manipulation;
}
/* Positions calibrated against PNG images — estimated, to be verified */
#choose-radio-hotspot    { top: 40%; height: 30%; }
#choose-continue-hotspot { top: 88%; height: 8%; }
#select-radio-hotspot    { top: 45%; height: 30%; }
#select-continue-hotspot { top: 88%; height: 8%; }
```

### Spinner CSS

New `@keyframes` rule + `#spinner` rule added to `<style>`:

```css
@keyframes spin { to { transform: translate(-50%, -50%) rotate(360deg); } }
#spinner {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
  width: 48px; height: 48px;
  border-radius: 50%;
  border: 3px solid rgba(255,255,255,0.25);
  border-top-color: #fff;
  animation: spin 0.7s linear infinite;
  z-index: 20;
  pointer-events: none;
}
```

### New Image Constants & Preload

```js
const CHOOSE_01_IMAGE = 'images/Choose How to Receive Money 01 P2P.png';

const SELECT_02_IMAGE = 'images/Select Account 02 P2P.png';
const CONGRATS_IMAGE  = 'images/Congratulations P2P.png';
// Rename existing: CHOOSE_IMAGE → CHOOSE_01_IMAGE
```

Preload array extended with four new images.

### New JS Functions

| Function | Trigger | Transition Type |
|---|---|---|
| `swapToChooseReceive02()` | `#choose-radio-hotspot` tap | Instant src swap |
| `slideToSelectAccount01()` | `#choose-continue-hotspot` tap | 300ms slide |
| `swapToSelectAccount02()` | `#select-radio-hotspot` tap | Instant src swap |
| `showProcessing()` | `#select-continue-hotspot` tap | Fade + 1s timer |

### `resetToBlank()` Extension

Must be extended to:
1. `clearTimeout(spinnerTimer)` 
2. `document.getElementById('spinner')?.remove()`
3. `current.style.opacity = '1'; current.style.transition = 'none'`

This ensures a clean reset from any state including `processing`.

### `showChooseScreen()` Rename

The line `flowState = 'choose-receive'` → `flowState = 'choose-receive-01'`. No other changes to that function.
