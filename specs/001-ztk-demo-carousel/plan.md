# Implementation Plan: PayCenter ZTK Demo Carousel

**Branch**: `001-ztk-demo-carousel` | **Date**: 2026-05-07 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/001-ztk-demo-carousel/spec.md`

## Summary

Build a single-file HTML demo that renders a generic CSS mobile phone frame on a dark charcoal background. Inside the phone screen, four Zelle P2P Enrollment Carousel images cycle in order via a left-slide transition (350ms, CSS transform). Clicking the right 50% of the phone screen advances the carousel; after image 004 it wraps back to 001. No frameworks, no build step, no server — open `index.html` by double-click.

## Technical Context

### Carousel (HTML + CSS + JS)

Two `<img>` elements live inside `.phone-screen` at all times:

```html
<div class="phone-screen">
  <img class="slide" id="slide-current" src="images/..." alt="">
  <img class="slide" id="slide-incoming" src="images/..." alt="">
  <div class="click-zone" id="click-zone"></div>
</div>
```

| Element | Initial CSS transform |
|---|---|
| `#slide-current` | `transform: translateX(0)` |
| `#slide-incoming` | `transform: translateX(100%)` |
| `.click-zone` | `position: absolute; right: 0; width: 50%; height: 100%; cursor: pointer; z-index: 10` |

Both `<img>` elements share: `position: absolute; width: 100%; height: 100%; object-fit: contain; transition: transform 350ms ease-in-out`.

### Transition Logic (JavaScript)

```
const IMAGES = [
  'images/Zelle P2P Enrollment Carousel Image 001.png',
  'images/Zelle P2P Enrollment Carousel Image 002.png',
  'images/Zelle P2P Enrollment Carousel Image 003.png',
  'images/Zelle P2P Enrollment Carousel Image 004.png'
];
let currentIndex = 0;
let isAnimating = false;

function advance() {
  if (isAnimating) return;
  isAnimating = true;

  const nextIndex = (currentIndex + 1) % IMAGES.length;

  // Stage incoming image off-screen right (no transition yet)
  incoming.style.transition = 'none';
  incoming.src = IMAGES[nextIndex];
  incoming.style.transform = 'translateX(100%)';

  // Force reflow, then enable transition and slide both
  requestAnimationFrame(() => {
    requestAnimationFrame(() => {
      current.style.transition = 'transform 350ms ease-in-out';
      incoming.style.transition = 'transform 350ms ease-in-out';
      current.style.transform = 'translateX(-100%)';
      incoming.style.transform = 'translateX(0)';

      setTimeout(() => {
        // Swap roles: incoming becomes current
        current.style.transition = 'none';
        current.src = IMAGES[nextIndex];
        current.style.transform = 'translateX(0)';
        incoming.style.transform = 'translateX(100%)';
        currentIndex = nextIndex;
        isAnimating = false;
      }, 350);
    });
  });
}

clickZone.addEventListener('click', advance);
```

The double `requestAnimationFrame` ensures the browser registers the `translateX(100%)` reset before the transition class is applied, preventing a no-op animation.
